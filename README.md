# Experiments About The Stinglet Project

This repo will contain everything needed to run experiments about Stinglet (and
its motivation), analyze, curate and plot the data. Most of the scripts and data
already exist elsewhere, in a very chaotic way, so we'll gradually move them
here where hopefully they'll be organized more rationally.

Currently there are only two folders:

- [`compare-kubelet-and-stinglet/`](compare-kubelet-and-stinglet/) — scripts and ancillary files to run experiments that compare Stinglet and kubelet. They are the ones that produce the data for the plots in the evaluation section of the full paper. Stay tuned for a README about them.
- [`plots/`](plots/) — everything needed to plot the experimental results, after the experiments have been run. For more details, refer to the README inside the folder.
